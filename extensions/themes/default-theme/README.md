# Default Theme (sample extension)

A minimal example **Theme** extension that demonstrates the `dotnetforge.extension.json` manifest
format. The CMS discovers it under `extensions/` and validates the manifest before it could be
enabled (see [Plugins](../../../docs/extension-development.md) and the admin **Plugins** page).

This sample ships only a valid manifest; a real theme would also provide layouts, templates, and
static assets. See `docs/theme-development.md`.
